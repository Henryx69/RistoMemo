# RistoMemo 🍴

> **Privacy-first** · La tua agenda personale dei ristoranti

Salva e organizza i tuoi ristoranti preferiti.
Funziona offline: i dati che inserisci restano sul tuo dispositivo.

### 👉 [🚀 Lancia RistoMemo](https://ristomemo.netlify.app/)

Compatibile con desktop e dispositivi mobili, installabile come app (PWA).
La versione ufficiale è disponibile solo su **ristomemo.netlify.app**.

---

## ✨ Funzionalità

| | Cosa puoi fare |
|---|---|
| 📍 **Salvare** | Ristoranti con voto ⭐, note, etichette 🏷️, telefono e giorni di chiusura 🗓️ |
| 🔍 **Cercare** | Per parole chiave, con filtro "aperto oggi" e solo preferiti |
| 🗺️ **Mappa** | Mini-mappa Google Maps nella scheda, solo quando tocchi "Mappa" |
| 🔗 **Condividere** | Un ristorante via testo, file JSON o QR code creato sul tuo dispositivo |
| 💾 **Backup** | Via email o file JSON, con conferma prima di sostituire i dati |
| 📱 **Offline** | Installabile come app, funziona anche senza rete |
| 🧭 **Guida** | Guida integrata nell'app |

---

## 🛡️ Privacy

L'autore non raccoglie né conserva dati personali sui propri server.
I tuoi ristoranti sono salvati solo sul tuo dispositivo (`localStorage`), senza database né account.

**Servizi esterni, e quando entrano in gioco**

| Servizio | Quando | Cosa può trattare |
|---|---|---|
| **Netlify** | Sempre | Ospita il sito: dati tecnici di connessione, come l'indirizzo IP |
| **Umami Analytics** | Sempre | Statistiche anonime e aggregate, senza cookie |
| **Google Maps** | Solo se tocchi "Mappa" | Nome e città o via del ristorante, più dati tecnici |

Font, librerie e codici QR sono forniti dal sito stesso: nessun altro servizio esterno viene contattato per usarli.

👉 [Privacy Policy completa](https://ristomemo.netlify.app/privacy.html)
