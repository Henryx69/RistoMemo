RistoMemo 🍴

Privacy-first restaurant tracker — La tua agenda personale dei ristoranti

RistoMemo è una web app privacy-first che ti permette di salvare e organizzare i tuoi ristoranti preferiti. Funziona offline: i dati che inserisci restano esclusivamente sul tuo dispositivo.

✨ Funzionalità
📍 Salva e organizza i tuoi ristoranti preferiti
⭐ Valutazioni e note personali
🏷️ Etichette personalizzate per ogni ristorante
🗓️ Giorno di chiusura con filtro "aperto oggi"
🗺️ Mini-mappa Google Maps integrata nella scheda
🔍 Ricerca avanzata per parole chiave, filtri per giorno e preferiti
💾 Backup e ripristino dati via email o file JSON, con conferma prima di sostituire i dati
🔗 Condividi un ristorante via testo, file JSON o QR code (il QR è creato sul tuo dispositivo)
📊 Contatore contestuale dei ristoranti salvati
🧭 Guida integrata nell'app
🔒 Dati salvati solo sul tuo dispositivo (localStorage, nessun database)
📱 Funziona offline (PWA installabile)
🚀 Prova RistoMemo

👉 Lancia RistoMemo 👈

Compatibile con desktop e dispositivi mobili. Installabile come Progressive Web App (PWA).

La versione ufficiale è disponibile solo su ristomemo.netlify.app.

🛡️ Privacy

L'autore non raccoglie né conserva dati personali sui propri server. Le informazioni che inserisci vengono salvate localmente sul dispositivo tramite localStorage.

Nessun database né server proprio: i tuoi ristoranti restano sul tuo dispositivo
Nessun tracking personale
Statistiche anonime aggregate tramite Umami Analytics (privacy-friendly, nessun cookie)
Visualizzazione mappe opzionale tramite Google Maps (solo quando tocchi "Mappa")
Il sito è ospitato su Netlify, che può trattare dati tecnici di connessione come l'indirizzo IP
Font, librerie e codici QR sono forniti dal sito stesso: nessun altro servizio esterno viene contattato per usarli
